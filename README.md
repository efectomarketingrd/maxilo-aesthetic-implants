# Maxilo Aesthetic Implants — sitio web

Web del centro de la Dra. Celia Hernández Mauricio (Las Terrenas, Samaná, R.D.).
Next.js, bilingüe (español `/es` e inglés `/en`), con datos estructurados para Google.

- Textos de la web: `lib/content.ts`
- Teléfonos, correo, WhatsApp y dominio: `lib/site.ts`
- Colores y diseño: `app/globals.css`
- Logos: `public/brand/`

Cuando tengas el dominio, configúralo en Vercel y agrega la variable `NEXT_PUBLIC_SITE_URL` con la dirección final (por ejemplo `https://tudominio.com`).
